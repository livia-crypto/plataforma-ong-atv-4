# 🌍 Plataforma ONG

Aplicação web desenvolvida para conectar ONGs e voluntários, com foco em acessibilidade e boas práticas.

## 🚀 Tecnologias
- HTML5, CSS3, JavaScript modular (SPA)
- LocalStorage
- Acessibilidade WCAG 2.1 AA
- GitFlow + Versionamento semântico

## ♿ Acessibilidade
- Navegação por teclado
- Contraste mínimo 4.5:1
- Suporte para leitores de tela
- Modo de alto contraste (botão “Alto Contraste”)

## 🧠 GitFlow
Branches:  
- `main`: versão estável  
- `develop`: desenvolvimento  
- `feature/*`: novas funcionalidades  

Commits usam padrão semântico (`feat:`, `fix:`, `docs:` etc.)
